# 使用指南

给第一次使用 FlowBreak 的你：先从几个容易让自己忘记时间的应用开始，不必一次改变所有习惯。

> 当前仍处于发布准备阶段，不是已经上架的正式版本。设备支持范围和发布进度以 [当前状态](CURRENT_STATUS.md) 为准。网页只是界面预览，不能识别或阻断手机上的其他应用。

## 试用安装、更新与反馈

目前提供的是**知情、自愿的小范围工程试用 APK**，不是正式稳定版。计时与保护仍有未关闭问题，不要依赖它保障安全或替代系统限制。vivo/iQOO 仍不支持保护运行时，其他机型未测试的能力不作保证。

1. 向提供者索取同一交付目录中的 APK、中文说明和 SHA-256 清单。国内版与 Play 版选一种：国内版有可选无障碍强阻断，Play 版不含该服务。AAB 和标有 `unsigned` 的 CI APK 不是可直接安装包。
2. 先阅读限制，再在 Android 文件管理器中打开 APK；如系统询问，只为这次安装按需允许可信来源，完成后可关闭该授权。系统或安全软件阻止时停止，不绕过安全检查。
3. 工程包使用 Android Debug 签名且可调试，并非正式生产证书。提示“签名不一致”“与现有包冲突”“版本过低”时停止并反馈，**不要为强装而卸载、清数据或尝试降级**。安装来源、证书或版本不同不保证无损更新；当前没有导入恢复功能。
4. 新用户安装后按下方步骤完成设置，再检查真实保护状态。发现时间异常、保护失效或误阻断时，在应用内停止保护，并在系统设置撤销该应用的相关权限；不要继续依赖保护显示。
5. 可向 `15015091629@163.com` 自愿反馈（该支持邮箱收发尚未实测）。建议只提供版本/渠道、手机型号与 Android/ROM 大版本、简短操作和预期/实际结果、是否影响日常使用。没有固定 24 小时要求。

反馈截图先遮住个人信息；不要公开完整 JSON 导出、目标应用列表、详细使用时间线、原始日志、账号或密钥。确需诊断时另行明确同意，优先用应用内脱敏分享；即使脱敏仍可能披露设备环境。只在本机存储不等于可调试工程包适合敏感或对抗性使用场景。

## 第一次设置

1. 在 Android 应用中阅读引导，进入权限设置。
2. 开启“使用情况访问”和“悬浮窗”两项必需权限，然后继续。通知、电池优化、自启动等是条件性或可选设置；不支持的设备不要继续尝试用更多权限换取保护。
3. 选择连续使用限额和休息时长。页面会直接展示不同提醒阶段对应的分钟数。
4. 点击“受限应用”，选好需要管理的应用并保存。可以按名称搜索、只看已选、清空后重新选择；这些应用共享连续使用时间。返回后，刚才选的限额与休息时长仍会保留。
5. 完成设置，回到首页检查“保护状态”。不要只凭开关开启就判断保护已经可用：权限、运行心跳和设备支持范围也会影响实际状态。

具体阈值、休息解锁与紧急使用规则见 [产品行为规范](PRODUCT.md)。应用内“我的 → 使用指南”也能随时查看常见问题。

## 给自己一个短暂休息

从首页点击“开始休息”，选择眼部放松、伸展或呼吸引导。按舒服的幅度做，不适时停止动作；可以关闭环境音。界面会显示剩余时间和当前步骤。

完整休息与提前退出不是同一件事。提前结束不会获得访问窗口；Android 上由设备时间与原生状态校验是否真正完成，网页倒计时不能作为手机保护证据。

## 看懂统计，而不是被数字催促

- “今日”“近7天”“近30天”分别展示当天和滚动时间窗口，不是自然周或自然月。
- 统计的是受限应用时间，不是整台手机总使用时间。
- 逐应用分布目前只提供今日数据；最近多天视图不会用今日占比冒充历史占比。
- “其他应用”合并超出展示数量的项目，仍使用完整总时长作为占比分母。
- “正在读取”“暂时无法读取”和“暂无记录”表示不同状态。读取失败时，原生界面不会拿网页缓存补成看似有效的数字；可以就地重试。
- 每日“有帮助 / 一般 / 没帮助”仅记录个人感受，可以修改，只保存在本机。它不是医学评价或健康疗效证明。

## 提醒不及时或保护不可用

1. 打开“我的 → 效果验证与运行诊断”。
2. 检查设备是否在当前支持范围、必需权限是否仍然有效、最近心跳是否可用。
3. 在支持设备上，进入权限页的“提升后台稳定性”查看对应品牌建议。Play 和国内版都有后台设置入口；专用入口不可达时会尝试应用详情或系统设置。打开设置不代表已授权，FlowBreak 也无法读取厂商白名单；“限制后台运行”警告独立于电池优化豁免。具体路径与范围见 [OEM 兼容与后台设置](OEM_COMPATIBILITY.md)。Android 或厂商系统不给应用执行时间时，实时提醒仍可能延迟；开启可选权限不能保证永不延迟。
4. 如果首页显示保护服务未运行，且设备支持、两项必需权限有效、已经选择受限应用并且没有暂停，可点击「恢复保护」。这是一次手动恢复请求，不会后台反复启动，也不等于已经恢复；只有原生状态确认后才显示保护可用，等待心跳时应继续留意状态。恢复中仍以你的暂停选择为准；失败会保留真实原因。不支持的设备或缺权限时不会用此入口绕过限制。
5. 部分数据读取失败时可以刷新。诊断导出用于排查，不等于长时间稳定性或真机验收通过。

浏览器中会明确说明无法验证原生运行状态，也不会生成一份假装来自 Android 的诊断文件。已知平台限制见 [已知问题](KNOWN_ISSUES.md)。

## 保存、导出与清除

在“我的 → 隐私与数据”可以导出 JSON。完整导出可能包含昵称、应用选择与使用明细，请自行妥善保管，不要直接公开分享。

清除需要再次确认；不确定时选择“保留数据”。确认永久清除会停止保护并删除本机设置、记录与进度，无法撤销。卸载也会导致本机数据丢失。当前没有数据导入、账号恢复或云同步功能，导出文件不能被当作已经支持换机还原的承诺。

完整处理规则见 [产品隐私说明](../PRIVACY.md)；这不是已正式托管的商店政策网页。

## 调整你的空间

“我的 → 健康目标与提醒”可修改昵称、展示身份、每日目标和休息背景。每日目标用于参考，不改变连续使用阻断阈值；背景预览与实际休息主题保持一致。

系统中开启“减少动态效果”后，界面会相应减少动画。网页允许缩放，按钮具有键盘焦点；休息和清除确认等关键操作提供明确的名称或说明。
