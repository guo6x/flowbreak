# 集成风险矩阵

本文是跨域集成风险索引，不取代产品规范、缺陷台账或发布状态。产品目标以 [`PRODUCT.md`](PRODUCT.md) 为准；当前实现以选定的工作树源码为准；候选身份、测试和设备结论以 [`CURRENT_STATUS.md`](CURRENT_STATUS.md)、[`TESTING.md`](TESTING.md)、[`KNOWN_ISSUES.md`](KNOWN_ISSUES.md) 为准。本文件不保存动态 SHA、CI Run、产物摘要或门禁状态。

## 审查范围与证据边界

- 本矩阵记录有待设计、实现或验收留意的跨域风险，不说明任何候选当前已通过。
- 集成过程中可能同时存在已提交基线与未提交代码/测试/工作流/文档 WIP；要认定其进入候选，必须先审阅最终差异并冻结候选 SHA。源代码被接通不等于编译、回归或审阅通过。
- 其他分支的测试、旧 CI、签名包和既有 AVD 只对它们自己的来源与范围有效；不得转移到新的集成候选。最终候选的精确验证快照只记录在 `CURRENT_STATUS.md` 与 `TESTING.md`。
- `FB-P1-08 / Gate F` 的状态、历史设备失败的限制和 Gate G/H/I 当前状态见 `CURRENT_STATUS.md`、`KNOWN_ISSUES.md` 与 `RELEASE.md`。模拟器可用于受控功能验证，但不替代真实设备/OEM 调度验收或 24 小时稳定性运行。

| REST 启动反馈与页面对账 | UI 必须将“命令已发出”“原生已接受”“RESTING 已持久化”作为不同状态；只能从带有效开始时间和时长的原生 RESTING 状态展示倒计时。当前候选已为 BEGIN/CANCEL 加入 UUID request token，并处理 BEGIN 尚未确认时页面卸载后的同 token 取消；自动化受控覆盖已完成。 | 命令排队或原生执行延迟时，过期的 BLOCKED 快照可能被显示成休息已开始；Web 计时器也可能与原生取消、完成或后台状态变化失配；卸载与延迟 BEGIN 的竞态可能留下未取消的原生休息。 | 以原生确认的 RESTING 状态为准，为长等待提供明确可恢复出口；仍需独立审阅和真实设备验证慢启动、失败、取消、切后台/恢复、BEGIN 未确认时卸载，以及同 token 去重。保持 **PENDING_VALIDATION**，不把自动化/AVD 证据写成 Gate F 通过。 |
| REST 原生证据、作弊检测与完成完整性 | 休息开始、取消、完成、恢复必须使用同一原生状态机和会话身份，且不能让 UI 推断原生结果。当前候选已为 `completeRestAndUnlock` 加入 `restSessionId` 绑定，并在唯一 monitor Handler 上回放完整 REST UsageEvents；回放查询/coverage 失败时 `DEFER`，完整目标历史达到 5 秒走取消路径，低于阈值才进入 completion coordinator。自动化受控覆盖已完成，但设备/独立审阅仍未关闭风险。分享白名单排除 `runtimeTracking`；当前源码无 `restCheatEvidence` 字段。 | 若未先对账完整 REST 历史，完成可能覆盖迟到的目标使用/取消；阈值边界、查询失败和窗口覆盖缺口都可能造成错误授予或永不完成。单靠 UI 倒计时、模拟 UsageEvents 或当前代码形态不能证明设备上可靠执行。增加运行证据时还可能越过隐私分享边界。 | 把“命令受理/服务提交/REST 全窗已对账/完成授权”作为不同阶段。测试完整/不完整 UsageEvents coverage、查询异常时 DEFER、阈值前后边界、重复完成与取消交错，并确认拒绝路径无 GRACE 副作用。自动化/AVD 只能记为相应受控证据，不能关闭 `FB-P1-08` / Gate F；保持分享字段最小化。 |

## 完成判定

此文档只做风险梳理；不代表整合验收、发布批准或真机等效验收。收敛时需逐项复审改动、按最终 SHA 重跑前端/双渠道 Android/依赖与隐私静态检查及产物溯源，并在 AVD 上验证可控安装与 REST 状态链路；详细结论只写入单一事实源。`FB-P1-08 / GATE F`、签名版本升级、OEM/真机和发行方/商店要求仍按各自门禁处理，不能由模拟器或本矩阵替代。
