## 1. 应用及数据处理目的

FlowBreak 是一款 Android 手机使用习惯管理工具。你自行选择希望减少使用的应用与时长；在你授权相关系统权限且监控能够正常运行的情况下，FlowBreak 以 Android 提供的使用情况与窗口切换信号为基础，计算使用时长、提醒和执行休息引导。

FlowBreak 的设计以本地处理为主，当前产品未要求注册账号、未接入广告账号或第三方行为分析服务。**本描述必须在最终 Play/Domestic APK 的网络和依赖核查后确认**。不同设备的 Android/OEM 后台限制可能影响检测与阻断；应用不会保证所有设备实时、持续或绝对有效。

## 2. 本地访问、保存和生成的数据

为提供用户主动选择的功能，应用可能在设备上保存：

- 被选为受限目标的应用包名、配置和连续使用时长累计值；
- 限制、提醒、阻断、休息、紧急解锁以及回到目标应用等本地操作事件；
- 用户主动选择的每日反馈、积分、成就和连续休息记录；
- 为保证保护能力可核对而生成的服务心跳、权限与运行诊断、状态机与防作弊计数；
- 必要的本地崩溃日志（如程序产生）。

上述数据通常在应用私有目录的 SharedPreferences、Room 数据库和本地缓存中处理。**脱敏诊断不应包含应用页面/输入内容或目标应用包名，但诊断仍可能含设备/时间与行为计数等可关联信息；请在对外分享前检查目标接收者。**

## 3. 权限与功能对应关系

| Android 权限 / 功能 | 用途 | 用户是否可控制 |
|---|---|---|
| 使用情况访问 | 识别当前应用并计算用户选择的目标应用的使用时长；不会读取目标应用页面文本 | 系统设置中授权/撤销；撤销后相关保护无法正常运行 |
| 悬浮窗 | 到达限制条件后显示提醒或阻断页面 | 系统设置中授权/撤销 |
| 通知与前台服务 specialUse | 提供监控运行状态通知、阶段提醒和后台服务运行 | 按系统能力调整/关闭；Android 系统可能限制 |
| 电池优化豁免 / 自启动（因设备而异） | 尽量减少被系统挂起或清理的概率 | 用户在厂商系统设置中选择；不保证永久后台运行 |
| 无障碍服务（仅国内版，可选） | 监听前台窗口所属应用，在限制触发时尝试返回桌面；不读取或保存页面内容、聊天消息或输入文本 | 需要独立显著告知后由用户明确选择，再到系统设置手动授权，可随时撤销 |
| 文件分享/本地数据导出 | 在用户选择时生成包含其数据的 JSON 文件，经 Android 系统分享面板交给用户自行选择的目的地 | 用户主动触发，接收应用的隐私实践由其自行决定 |

Google Play 版不应包含 Domestic 无障碍服务或功能声明；两渠道以最终二进制及 Manifest 校验结果为准。

## 4. 数据传输与第三方

当前设计不依赖应用服务器同步上述保护数据，但 **Android Manifest 中仍声明 INTERNET**，且 Android 框架、打包后的 SDK、应用页面及用户主动的系统分享行为需要按实际最终二进制核查。

- 应用不会自行把用户的应用使用情况、聊天消息或页面内容上传到项目服务器作为其核心流程（以正式发布前的最终核查为前提）。
- 用户主动选择“导出/分享数据”时，JSON 文件可能由其选择的第三方应用、云盘或通信应用接收；该接收应用如何处理数据受其自身规则约束。
- 若未来新增 SDK、网络上传、帐号或云同步，会在上线前重新评估 Data safety、隐私政策、告知及授权要求，不默认为现有政策已覆盖。

不得在没有独立验证的情况下承诺“绝不产生任何网络请求”或“所有脱敏信息都绝不具备识别性”。

## 5. 数据保存与删除

在不清除数据时，设置、历史使用汇总、事件与进度信息通常保存在该设备应用私有目录中。用户可在应用内“隐私、数据与关于”里主动导出本地数据，并使用“清除全部本地数据”删除应用保留的数据。安卓卸载过程通常会移除应用私有目录数据，**用户先前主动导出给其他 App 的副本不会因本应用的清除或卸载而自动删除**。

如果系统或设备备份存在额外副本，需要以最终 Android 配置与设备备份政策为准；目前主 Manifest 标示 `android:allowBackup="false"`，正式二进制仍应复核。

## 6. 用户请求与政策变更

用户如需了解数据处理或联系项目运营者，可通过发布前确认的官方联系方式提出请求。更新将标示新版本与生效时间，并在应用内或公开地址保持可见；涉及重大处理方式变化时需重新评估用户告知与选择。
