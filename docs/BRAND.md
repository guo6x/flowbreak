# 品牌与界面设计参考

本文供维护界面和品牌资产的开发者使用，不定义保护规则。产品行为仍以 [PRODUCT.md](PRODUCT.md) 为准。

## 核心表达

**FlowBreak · 给注意力，留一点空白。**

视觉语气是安静、可信、不过度催促。使用温暖的浅色底、森林绿与柔和蓝，不用高分、排行榜或未经验证的健康结论制造压力。时间、状态与下一步操作优先于装饰和反馈收集。

## 标志

![FlowBreak 标志](../app/src/assets/icon.svg)

两片错开的流动叶形，在中间形成一段“暂停”的留白。深绿承托米白与浅绿，保留单色和小尺寸下的基本辨识度；不依赖文字、渐变、细线或外部字体。

- 唯一可编辑图形源：`app/src/assets/icon.svg`，矢量 `viewBox="0 0 64 64"`。
- React 入口：`app/src/components/Brand.tsx`；标志与文字组合使用 `Brand`，纯装饰标志使用 `BrandMark`。
- 浏览器、Android 各密度启动器、圆形图标、adaptive foreground、Android 单色主题图标和启动图由同一源派生。
- 不直接编辑派生 PNG / XML。修改源之后，在 `app/` 执行：

```bash
npm run brand:generate
npm run test:brand
```

生成器位于 `app/scripts/generate-brand-assets.mjs`。验证包括矢量/XML 一致性与 PNG 像素一致性，不依赖压缩器在不同系统上产生完全相同的字节。

## 颜色与排版

| 用途 | 颜色 |
| ---- | ---- |
| 主操作 / 强调 | `#247353` |
| 深绿 / 品牌底色 | `#1C5943` |
| 次要信息 / 辅助操作 | `#367C98` |
| 提醒 / 暖色强调 | `#A36519` |
| 错误 / 不可撤销操作 | `#BF4545` |
| 页面背景 | `#F4F7F3` |
| 正文 / 次要文字 | `#1E3328` / `#627168` |

界面 token 的实现源在 `app/src/App.css`；Android 资源颜色在 `app/android/app/src/main/res/values/colors.xml`。变更时共同检查文字对比度，不能只改主色。

使用本地系统字体栈，包含常见中文系统字体，不加载 Google Fonts 或远程字体。正文基础字号为 16px；说明文字和数字按信息层级调整。卡片使用轻描边与克制阴影，不依赖大片阴影分层。

## 页面约定

- 页面从小屏开始设计，宽屏主内容保持居中的阅读列。底部导航与固定保存条必须与主内容列对齐。
- 关键按钮至少提供约 44px 的触控区域；选择项提供 `aria-pressed`，仅图标按钮要有可访问名称。
- 完成、提前退出、清除等动作要说明后果。破坏性确认优先聚焦安全选项，取消后返回原入口。
- 真实休息背景由 `app/src/pages/rest-mode/themeData.ts` 管理；偏好页与个人页预览复用相同数据，避免预览与使用时不一致。
- 响应系统减少动态效果设置；网页允许缩放，不限制用户用放大来阅读。
- 空、加载、失败、不可验证必须分别表达。网页预览不显示虚构的 Android 保护成功。

逐页检查方法与验证边界见 [TESTING.md](TESTING.md)；用户操作说明见 [USER_GUIDE.md](USER_GUIDE.md)。
