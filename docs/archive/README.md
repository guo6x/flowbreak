# docs/archive — 历史资料归档

本目录下的所有内容**仅为历史记录**。

- 不得作为当前产品规则、架构或测试状态依据。
- 不得把其中的旧结论当作「当前真相」引用；当前事实以 `docs/README.md` 的事实优先级为准。
- **任务完成报告代表当时执行 AI 的自述，不等同于独立验收结果**。历史报告中的「无遗留问题」「完全解决」「最终完成」等表述不能覆盖后来的真机证据（2026-08-12 Redmi 真机 FAIL；该轮发现的 P1/P2 已于 2026-08-14 R1–R4 复测后 RESOLVED，见 `KNOWN_ISSUES.md`）。
- 归档文件保留原文，不改写；需要引用其中的有效信息时，以迁移后的当前文档为准。

## 分类

- `product/` — 旧产品蓝图、旧锚点文档（愿景与历史规则）
- `prompts/` — 历史执行提示词（一次性任务分派）
- `progress/` — 历史进度报告、验证记录、项目记忆流水账
