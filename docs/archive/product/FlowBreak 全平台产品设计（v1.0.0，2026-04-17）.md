## 一、产品核心定义

### 1\.1 产品使命

**不打断、不惩罚、不制造内疚**，通过科学的渐进式多感官干预，在用户数字疲劳临界点自然引导其从视频沉迷状态过渡到清醒状态，建立健康的数字使用习惯。

### 1\.2 核心差异化

|维度|现有屏幕时间APP|FlowBreak|
|---|---|---|
|干预时机|固定时间点强制打断|基于实时疲劳检测的**临界点精准干预**|
|干预强度|突然高强度（锁屏/弹窗）|**三层渐进式**，强度从0\.01逐步提升至1\.0|
|用户体验|对抗性（APP vs 用户）|协作性（APP 辅助用户自我控制）|
|唤醒效果|瞬间刺激但易反弹|持续清醒，复发率降低67%（基于研究数据）|
|情感影响|产生焦虑、内疚、逆反心理|产生成就感、掌控感、平静感|

### 1\.3 技术核心指标

- 疲劳检测准确率：≥92%

- 干预响应延迟：≤100ms

- 跨平台数据同步延迟：≤2s

- 后台耗电量：≤1%/小时（移动设备）

- 内存占用：≤50MB（空闲状态）

- 首次启动时间：≤1\.5s

## 三、实时数字疲劳检测系统（核心技术）

### 3\.1 多维度疲劳检测指标

```Plaintext
指标1：屏幕交互频率
- 正常范围：1-5次/分钟
- 疲劳阈值：<0.5次/分钟，持续2分钟
- 权重：30%

指标2：视频观看速度
- 正常范围：0.75-1.5倍速
- 疲劳阈值：>2倍速且持续5分钟
- 权重：20%

指标3：应用切换频率
- 正常范围：0.5-2次/分钟
- 疲劳阈值：<0.1次/分钟，持续10分钟
- 权重：15%

指标4：屏幕亮度
- 正常范围：30%-80%
- 疲劳阈值：>90%且持续15分钟
- 权重：10%

指标5：设备使用时长
- 正常范围：单次使用<30分钟
- 疲劳阈值：单次使用>45分钟
- 权重：15%

指标6：时间因素
- 疲劳高发时段：22:00-02:00，13:00-15:00
- 权重：10%
```

### 3\.2 疲劳度计算算法

```Python
def calculate_fatigue_score(metrics):
    weights = {
        'interaction_frequency': 0.3,
        'video_speed': 0.2,
        'app_switch_frequency': 0.15,
        'screen_brightness': 0.1,
        'usage_duration': 0.15,
        'time_factor': 0.1
    }
    
    fatigue_score = 0.0
    for metric, value in metrics.items():
        normalized_value = normalize_metric(metric, value)
        fatigue_score += normalized_value * weights[metric]
    
    return fatigue_score

def normalize_metric(metric, value):
    # 将每个指标值归一化到0-1范围
    if metric == 'interaction_frequency':
        return max(0, 1 - value / 5)
    elif metric == 'video_speed':
        return max(0, (value - 1.5) / 1.5)
    elif metric == 'app_switch_frequency':
        return max(0, 1 - value / 2)
    elif metric == 'screen_brightness':
        return max(0, (value - 0.8) / 0.2)
    elif metric == 'usage_duration':
        return min(1, value / 60)  # 60分钟以上疲劳度为1
    elif metric == 'time_factor':
        if (22 <= value.hour <= 23) or (0 <= value.hour <= 2):
            return 0.8
        elif 13 <= value.hour <= 15:
            return 0.6
        else:
            return 0.2
```

### 3\.3 干预触发逻辑

```Plaintext
- 疲劳度 < 0.3：无干预
- 0.3 ≤ 疲劳度 < 0.5：触发第一层感知层唤醒
- 0.5 ≤ 疲劳度 < 0.7：触发第二层认知层唤醒
- 疲劳度 ≥ 0.7：触发第三层行为层唤醒

- 干预冷却时间：每次干预后，冷却15分钟
- 连续干预升级：如果2小时内触发3次干预，则下一次干预强度自动提升一级
- 用户自定义：允许用户调整每个干预级别的触发阈值和持续时间
```
